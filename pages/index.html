CSS Override — Portrait (OBS Studio Browser Source)

Single-room portrait layout for OBS. Set the browser source URL to https://symposium.orfe.princeton.edu, resolution to portrait (e.g. 1668×2388), then paste override-room.css into the Custom CSS field. Uncomment the line for the target room.
